# projects：一件長期的事一夾

> 會做好幾週、要記進度與決定的事，才開一夾：一個計畫、一篇論文、一門課、一個專題。一兩天做完的事記在 `memory/手上的事.md` 就好。
> 跟夥伴說「幫我開一夾：＿＿＿」，它照下面的格式建。夾名用這件事的名字，不加日期。開夾的同時，在 `memory/手上的事.md`〈進行中〉加一列指到這一夾，報到的「進行中 M 件」才算得到它。

每一夾兩個檔：

**`README.md`**（現在到哪）

```
# <這件事的名字>

| 項目 | 內容 |
|---|---|
| 這是什麼 | 一句話 |
| 跟誰一起 | 寫角色，不必寫全名 |
| 截止 | 日期 |

## 現在到哪（日期）
- 

## 等誰回
| 事 | 等誰 | 從哪天起 |
|---|---|---|

## 走過的路
- 日期　發生了什麼
```

**`決定紀錄.md`**

```
# 決定紀錄：<這件事的名字>

## 決定
- 日期｜決定｜依據（誰說的、哪封信、哪份文件）

## 提過、還沒決定的
- 
```

「決定」只記確認過的；別人的提議放在「提過、還沒決定的」。開夾時主人講的事先寫進 README；他說「定了」才進決定紀錄。
