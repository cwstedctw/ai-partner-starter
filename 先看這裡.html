我的 AI 夥伴：起手資料夾

這個資料夾讓你的 AI（ChatGPT 桌面版的 Codex，或 Claude 的 Code）變成會記事、照規矩做事的夥伴：記你每門課的作業與手上的事、做作業時當家教不當代筆、幫你查核資料來源、整理小組討論。修課的同學、研究生、老師、上班族都能用；用久了，它就是你自己的版本。

你不用打指令。灰色框裡的句子按「複製」、貼給 AI，它一步一步做，每一步先問你。你只做三種事：電腦問「是否允許」時按「是」、在瀏覽器登入自己的帳號、聽它說明之後說「好」。

下面一共 12 項，前 10 項人人要做，其餘選配。每一項都有「完成判準」：打勾之前照它看一眼，把關的人是你自己。第一次做，請留一個晚上；要下載安裝的幾項，網路慢時會等比較久。

貳　一項一項做

1裝 AI 桌面版，找到可以叫它動手的那個模式你自己裝・Windows／Mac 都要

為什麼：聊天網頁只會回答文字。桌面版裡的「Codex」（ChatGPT）或「Code」（Claude）才會打開你的資料夾替你做事，這份資料夾靠的就是它。

ChatGPT 桌面版（裡面有 Codex）

  1. 先到 chatgpt.com 登入或註冊，記住用的是哪個帳號。桌面版要用同一個帳號登入。
  2. Windows：打開 Microsoft Store，搜尋「ChatGPT」，會看到兩個，裝名字就叫「ChatGPT」的那一個，不是「ChatGPT Classic」（Classic 是舊版，裡面沒有 Codex）。Mac：到 chatgpt.com/download 下載，拖進「應用程式」。
  3. 打開、登入。左上角寫著「ChatGPT」的選單可以切 ChatGPT／Codex，切到 Codex。找不到 Codex：先確認登入的是同一個帳號、裝的不是 Classic；還是沒有，停在這一項，用下面的求救句問，不要往下做。

Claude 桌面版（裡面有 Code）

  1. 到 claude.ai/download 下載、安裝、登入。
  2. 切到 Code 分頁。Claude 的 Code 要付費方案（Pro 以上），免費帳號沒有。
沒有付費方案的同學：ChatGPT 免費帳號也能用 Codex，但額度有限，做到一半可能要等。課堂上老師若指定了別的免費工具（例如 Antigravity；它要用個人 Gmail 登入，學校信箱登不進去），照老師的；打開同一個資料夾、貼「請讀 AGENTS.md，報到。」一樣能用，只是畫面與下面寫的不同。

兩家選一家就好。哪個方案有這個功能、額度多少，各家常改；以你登入後畫面上看到的、和官方方案頁為準。

桌面版打得開、登入的是你自己的帳號、切到 Codex（或 Code 分頁）之後看得到一個可以打字的輸入框。先不要叫它做事。
我在裝＿＿（ChatGPT 桌面版／Claude 桌面版），卡在＿＿＿（例如：登入被擋／裝好打不開／找不到 Codex／不確定裝的是不是 Classic），畫面如附圖。請告訴我畫面上發生什麼事，再一步一步帶我。我用的是＿＿（Windows／Mac）。

2跟 AI 夥伴打第一聲招呼1 分鐘

為什麼：先確認它會回話。後面卡住時，才分得清是工具壞了、還是某一步做錯。

你好。請告訴我：你現在看得到哪一個資料夾？如果沒有打開任何資料夾，也直接告訴我。
一分鐘內它回了一段話，有沒有資料夾都算。這代表工具會動、登入成功、網路通。它要你先選一個資料夾才肯對話的話，先做第 5 項，再回來貼這句。
我貼了一句話給你，但＿＿＿（例如：沒有回應／回了錯誤訊息／說額度用完），畫面如附圖。請告訴我可能是什麼原因，我該先檢查什麼。

3調一下授權：要它「先問我」1 分鐘

為什麼：這一項只決定一件事：AI 要在你的電腦上跑指令、碰資料夾以外的東西時，要不要先問你。選「會先問我」的那一種。

  • ChatGPT 的 Codex：輸入框正下方有一個權限選單，選 Ask for approval（中文介面是「要求核准」）。不要選 Full access（完整存取權）。
  • Claude 的 Code：輸入框附近的權限模式選會先詢問的那一種（預設就是）；不要選略過所有確認的模式。

字樣會隨版本變，找意思對得上的那一個。之後它跳框請你同意時這樣判斷：先看它在對話裡說這一步要做什麼，跟框裡寫的對得上（例如它說要裝 Git，框裡有 git 這個字）就同意，選「只同意這一次」那種；看不懂就按拒絕，再問它「這一步要做什麼」。拒絕不會弄壞東西。

你說得出自己選的是哪一個，而且不是「全部自動、什麼都不問」的那一種。
我在找 AI 桌面版的權限設定，想選「執行指令前先問我」的那一種，但找不到（或不確定哪個是），畫面如附圖。請告訴我該選哪一個、每個選項差在哪。

4GitHub 帳號你自己做・5 分鐘

為什麼：夥伴資料夾會越用越有價值，要有地方備份、換電腦抓得回來。GitHub 上可以開「只有你看得到」的私人資料夾（GitHub 把一個資料夾叫做 repo；私人的叫 Private）。

  1. 到 github.com/signup，填 Email、設密碼。
  2. 取一個帳號名（Username）：會出現在網址上，用英文名或英文名加數字，之後改起來麻煩。
  3. 到信箱收驗證碼填回網頁；後面的問卷可以按 Skip。跳出教育方案之類的廣告畫面，關掉就好。
  4. 登入時如果 GitHub 要你設定兩步驟驗證（2FA），照它做：手機裝一個驗證 App（Google Authenticator 或 Microsoft Authenticator），掃網頁上的方格圖，把六位數字填回去，最後把那一串復原碼存好。沒被要求就先不用。
能登入，看得到自己的個人頁（網址是 github.com/你的帳號名）。
我在 GitHub＿＿＿（註冊帳號／設定兩步驟驗證／接受邀請），卡在＿＿＿（例如：收不到驗證信／畫面要我做一件我看不懂的事），畫面如附圖。請告訴我這一步在做什麼，再一步一步帶我完成。

5決定資料夾放哪，建一個空資料夾2 分鐘

為什麼：夥伴資料夾不能放在會自動同步的地方。「同步」＝你一改檔案，雲端（OneDrive、iCloud、Google 雲端硬碟）就自動複製一份上網；它會跟 Git 的版本紀錄打架：檔案被鎖住、出現重複檔、紀錄對不上，而且不會跳出任何錯誤訊息。Windows 的「桌面」「文件」常常就在 OneDrive 裡。

  • Windows：建 D:\AI夥伴；沒有 D 槽就 C:\AI夥伴。（打開檔案總管 → 進 D 槽 → 空白處按右鍵 →「新增」→「資料夾」。）
  • Mac：家目錄底下建 AI夥伴。（Finder 選單「前往」→「個人專屬」→ 按右鍵「新增檔案夾」。）

不確定那個位置會不會被同步，問 AI：

請幫我確認：這台電腦的桌面與文件資料夾，有沒有被 OneDrive、iCloud 或 Google 雲端硬碟同步？我想把一個新資料夾放在不會被同步的位置；只把建議位置的完整路徑印給我看，先不要建任何資料夾。

然後讓 AI 桌面版打開這個空資料夾：

  • ChatGPT 的 Codex：輸入框上方點「選擇專案」→「新專案」→「來源資料夾」選剛建的資料夾 →「建立專案」。
  • Claude 的 Code：在 Code 分頁開一個新的工作階段，它問要用哪個資料夾時，選剛建的資料夾。

按鈕字樣會隨版本變；找不到就截圖用下面的求救句問。「完整路徑」是資料夾在電腦裡的完整地址，例如 D:\AI夥伴。

資料夾建好了、是空的，完整路徑裡沒有 OneDrive、iCloud、Google Drive 的字樣；AI 桌面版已經打開這個資料夾。
我要在 AI 桌面版打開我剛建的空資料夾（路徑是＿＿＿），但找不到「開啟資料夾」在哪，畫面如附圖。請告訴我按哪裡。

6裝 Git，把起手資料夾抓進來，然後鎖住貼一段給 AI・5–15 分鐘

為什麼：Git 是替資料夾記住每一次修改的工具，「抓資料夾」「存版本」都靠它。抓好之後要「鎖住」：你之後寫的筆記推不回原本那一份，不會跑到別人那裡。這一項 AI 會分三小步做（裝 Git、抓資料夾、鎖住），每一步都會先問你。指令裡的 origin 是「這個資料夾預設連到 GitHub 上的哪一份」，no_push 是「只准抓、不准推回去」。

下面這段是寫給 AI 看的，裡面的英文指令你不用懂，整段複製貼上：

這個資料夾是空的，請幫我把起手資料夾抓進來。照下面做，每一步先跟我說要做什麼，我說好才做： 1. 資料夾路徑裡有 OneDrive、iCloud 或 Google 雲端硬碟，或資料夾裡已經有別的檔案：先停下來告訴我。 2. 打 git --version 看有沒有 Git。沒有的話：Windows 先告訴我會同意 winget 的來源條款和 Git 的授權，我說好才跑 winget install --id Git.Git -e --source winget --accept-source-agreements --accept-package-agreements；Mac 會跳出「安裝命令列開發者工具」的視窗，請我按安裝。跳出「是否允許」我來按。要管理員帳密或指令被擋，就停下來告訴我，不要改去別的網站下載安裝檔。 3. Windows 剛裝好叫不到 git 的話，第 4、5 步的 git 都改用完整路徑 C:\Program Files\Git\cmd\git.exe 來跑。 4. 跑 git clone https://github.com/cwstedctw/ai-partner-starter.git .（下載要一點時間，逾時請設長一點）。跳出 GitHub 登入視窗我自己登；任何帳號、密碼、代碼都不要替我輸入。 5. 抓好之後馬上跑 git remote set-url --push origin no_push，再跑 git remote -v 給我看，push 那一行要是 no_push。 做完這五步就停，告訴我做到哪。
  • Windows 可能跳「你要允許此應用程式變更你的裝置嗎？」：AI 剛說要裝 Git 之後跳的，按「是」。沒看到視窗就看工作列有沒有在閃的盾牌圖示。
  • Mac 可能跳「要安裝命令列開發者工具嗎」：按「安裝」，等幾分鐘到十幾分鐘。
它給你看的 git remote -v 裡，push 那一行是 no_push；資料夾裡出現 AGENTS.md、先看這裡.html、memory、runbooks 這些。
你剛剛幫我抓起手資料夾，但現在＿＿＿（例如：卡在一個視窗／出現 Repository not found／說裝好 Git 但叫不到），畫面如附圖。請先不要動，告訴我現在的狀況，再說下一步。
沒辦法用 Git 抓的人：下載 ZIP

請發這個資料夾給你的人改給你 ZIP 檔（或在 GitHub 網頁按綠色的 Code → Download ZIP）。在 ZIP 上按右鍵 →「全部解壓縮」，把解開的內容放進第 5 項的資料夾。ZIP 來的資料夾沒有版本紀錄，第 9 項存到自己的 GitHub 時，AI 會照手冊另外處理。

7報到1 分鐘

為什麼：資料夾裡的 AGENTS.md 是給 AI 的公約（它該怎麼工作、哪些事不能做）。它讀了，才是「你的夥伴」，不是一般的聊天機器人。每次開新對話第一句都是這句。

請讀 AGENTS.md，報到。
它的第一行是：主夥伴 · 你的資料夾路徑 · 手冊 6 本 · 進行中 0 件。路徑是第 5 項那個資料夾。（6 本是出廠的數字；之後你請它寫新手冊、記新的事，這兩個數字會跟著變。）
我貼了「請讀 AGENTS.md，報到。」，但你的第一行不是「主夥伴 · 路徑 · 手冊 N 本 · 進行中 M 件」的格式（或路徑不是我的資料夾）。請告訴我你現在打開的是哪個資料夾、裡面有沒有 AGENTS.md。

8裝 GitHub CLI，登入 GitHub貼一句給 AI・5–15 分鐘

為什麼：GitHub CLI（gh）是讓 AI 替你操作 GitHub 的小工具。裝好、登入一次，之後「存上去」「抓回來」你都只要說一句話。

請照 runbooks/裝工具.md 幫我把工具裝好。gws 先不要裝，等我說。

它會做的事，和你要做的事：

  1. 它先跑「檢查工具」，告訴你哪些已經有（OK）、哪些還沒有（MISSING）。
  2. 它說要裝 GitHub CLI，你說好；Windows 跳「是否允許」按「是」。
  3. 它請你把 AI 程式整個結束再打開（新裝的工具要重開才叫得到）。Windows 最保險是重新開機；Mac 按 Command＋Q。打開同一個資料夾，貼：
請讀 AGENTS.md 報到，然後繼續裝工具。
  1. 它可能會問你要用什麼名字和信箱：Git 每存一版會記是誰存的。用英文名或暱稱就可以；第 9 項存到 GitHub 時，它會改用 GitHub 給的隱藏信箱，你真的信箱不會出現在紀錄裡。
  2. 登入 GitHub：它給你一組八碼（像 A1B2-C3D4）。打開 github.com/login/device，貼上八碼，確認畫面寫的是 GitHub CLI、右上角是你的頭像，再按綠色的 Authorize。八碼幾分鐘就過期：過期了跟它說「八碼過期了，再給我一組」。
  3. 它把登入的帳號名念給你，你確認是自己的。
它貼出的檢查結果裡，git、gh 都是 OK，「GitHub CLI is logged in」，而且它念出來的帳號名是你的。想自己看一次：Windows 雙擊資料夾裡的 檢查工具.cmd（畫面是英文：OK＝有了，MISSING＝一定要但還沒裝，-- ＝選配）；Mac 雙擊 檢查工具.command（第一次可能說無法打開：在檔案上按右鍵 →「打開」）。
你在幫我裝 GitHub CLI（或登入 GitHub），但現在＿＿＿（例如：裝好了還是叫不到 gh／八碼貼上去說過期／畫面要我選一堆選項），畫面如附圖。請先不要動，告訴我狀況，再一步一步帶我。如果是學校管控的電腦裝不了，直接告訴我。
學校或單位配發、有管控的電腦可能裝不了。AI 會說「需要資訊人員」：把這一頁轉給資訊人員，或告訴老師、助教，或發這個資料夾給你的人。

9存到你自己的 GitHub貼一句給 AI・5 分鐘

為什麼：到這裡，資料夾還只在這台電腦上。存一份到你自己的 GitHub，電腦壞了、換電腦都抓得回來，而且每一版都留著。

幫我存到我自己的 GitHub

它會：把登入的帳號念給你確認 → 掃一遍有沒有像身分證號、手機的字 → 在你自己的帳號底下開一個私人（Private）的 repo，名字是 my-ai-partner → 存上去 → 把網址給你。

打開它給的網址，名字旁邊有 Private 這個字，網址裡的帳號名是你的。看到 Private 才算存好。
你在幫我把資料夾存到我自己的 GitHub，但現在＿＿＿（例如：說掃到疑似個資／說 origin 不是我的／推上去被拒絕），畫面如附圖。請先不要動，照 runbooks/存到我的GitHub.md 告訴我現在停在哪一步、為什麼停。
Private 不等於什麼都能放。別人的個資、研究資料、名單、帳號密碼，一律不放進這個資料夾（material/README.md 有四條判斷）。

10讓夥伴認識你5 分鐘

為什麼：它記得越多你的事，越不用每次從頭解釋。這些都寫在 memory/ 裡的文字檔，你隨時打得開、改得了。

幫我填 memory/我是誰.md。我用講的：我是＿＿＿（例：東華大二，修人工智慧概論），用＿＿（Windows／Mac），想請你幫我＿＿＿（例：記作業截止日、做作業時當家教、期末專題記進度）。

再替它取個名字（選做）：

你叫＿＿。請記在 memory/夥伴.md。

最後說：

幫我收工
打開 memory/我是誰.md 看得到它剛寫的內容；memory/log.md 最後多了今天的幾行；它回「存好了」（它會把今天的改動存到你第 9 項開的 GitHub）。
我請你填 memory/我是誰.md（或幫我收工），但我打開檔案沒看到變化。請告訴我你把內容存到哪個檔、完整路徑是什麼。

參　選配：讓夥伴處理信箱與雲端硬碟

11先走簡單的路：桌面版內建的連接選配・3 分鐘

為什麼：只是要它找信、讀信、整理重點、讀雲端硬碟的文件，不用另外裝東西。有沒有這個功能，看你的方案與帳號類型（學校帳號有時被學校關掉）。

  1. 在 ChatGPT 或 Claude 桌面版打開「設定」，找「連接器」（Connectors；ChatGPT 有時叫「應用程式」）。有些版本要先切回一般聊天模式才看得到。
  2. 在 Gmail、Google 雲端硬碟旁邊按「連接」，用你的 Google 帳號登入、按允許。
問它「我信箱裡最近一封來自＿＿的信在講什麼？」，它答得出來。
我想在 AI 桌面版連接 Gmail 和 Google 雲端硬碟，但在設定裡找不到連接器（或按了連接之後被擋），畫面如附圖。請告訴我該按哪裡；如果是我的帳號或方案不支援，也直接告訴我。

12進階：gws（把回信建成 Gmail 草稿、帶附件、整批處理）選配・20–40 分鐘

為什麼：gws 是 Google Workspace 的指令工具。第 11 項做不到的三件事它做得到：把回信直接建成 Gmail 草稿、帶上附件、一次處理很多封。草稿一律你自己在 Gmail 看過、自己按傳送；這個資料夾的公約與手冊不准 AI 寄信，它只建草稿。

先拿到一個檔：client_secret.json。它是「登入設定檔」，像一張通行證，告訴 Google「這個工具可以請使用者登入」。這個檔要從 Google Cloud（Google 給開發者用的後台）做出來，一般人自己做很麻煩，所以由老師（或發這個資料夾給你的人）做好給你。沒有這個檔，下面第 3 步會失敗。

老師沒有發這個檔，就跳過這一項，用第 11 項。不要用來路不明的 client_secret.json，也不要把自己的傳給別人。
  1. 把拿到的 client_secret.json 放進這個資料夾（或「下載」資料夾）。這個檔不會被存上 GitHub（已經擋掉了）。
  2. 貼給 AI：
我拿到 client_secret.json 了，請照 runbooks/裝工具.md 的〈gws〉幫我裝 Node.js、uv、gws，然後帶我登入。登入由我自己按。
  1. 它會一項一項裝（每項先問你），中間會再請你把 AI 程式整個結束重開一次。
  2. 登入：Windows 它會請你自己雙擊資料夾裡的 設定信箱.cmd。黑色視窗裡是英文，「WORK Google account」指你平常工作或上課用的 Google 帳號。瀏覽器打開後：選帳號 → 把它列的權限全部勾起來（少勾不會報錯，但之後某些功能會沒反應）→ 按繼續。視窗最後寫 OK login saved 就好了。Mac 由 AI 跑登入指令，瀏覽器一樣你自己按。
  3. 試一次：
請用 gws 在我的 Gmail 建一封草稿：寄給我自己，主旨「夥伴測試」，內文一句「這是 AI 夥伴建的草稿」。只建草稿，不要寄出，建好告訴我。
Gmail 的「草稿」裡多一封「夥伴測試」，「寄件備份」裡沒有（代表它沒寄出）。看完把這封草稿刪掉。
我在設定 gws，卡在＿＿＿（例如：找不到 client_secret.json／瀏覽器說「存取遭拒」或「這個應用程式未經驗證」／登入好了但建草稿說 403），畫面如附圖。請先不要重新登入，告訴我這個訊息是什麼意思、是我能解決的，還是要找給我檔案的人。
看到什麼意思
「存取遭拒」「Access blocked」「org_internal」登入設定檔不允許你這個帳號。換成對的帳號；還是不行，找給你檔案的人
「Google 尚未驗證這個應用程式」設定檔是測試用的。給你檔案的人說可以，才按「進階」→「繼續」
403 insufficient scopes登入時權限沒勾滿。請 AI 帶你重新登入，這次全部勾

肆　平常怎麼用

每次打開資料夾，第一句：

請讀 AGENTS.md，報到。

然後用自己的話講就好。幾個例子：

做完一天：

幫我收工

三個習慣，會讓它好用很多：

  • 一件事開一個新對話。對話太長，它會忘記規矩。
  • 它說「完成」，問它三題：這個說法哪來的？存到哪？有沒有動到別的檔？
  • 它記錯了就直接說「這個不對，改成…」，它會改記憶檔，下次就對了。
之後想做什麼跟夥伴說

附錄　不靠 AI，自己裝

AI 裝不了、或你想自己來的時候再看。裝好一樣之後，關掉視窗、開一個新的，新裝的指令才找得到。第一次用 winget 它會問要不要同意來源條款，打 Y 按 Enter。

Windows

按鍵盤 Windows 鍵，打 PowerShell，按 Enter。按「複製」後在視窗裡按滑鼠右鍵就是貼上，再按 Enter。

Git

winget install --id Git.Git -e --source winget

看 Git 裝好了沒（要看到 git version 2.…）

git --version

GitHub CLI

winget install --id GitHub.cli -e --source winget

登入 GitHub（照它問的選：GitHub.com → HTTPS → Yes → Login with a web browser，然後貼八碼）

gh auth login

看登入了沒（要看到 Logged in to github.com account 你的帳號名）

gh auth status

Node.js（要用 gws 才裝）

winget install --id OpenJS.NodeJS.LTS -e --source winget

uv（要用 gws 寫信才裝）

winget install --id astral-sh.uv -e --source winget

gws（注意是 npm.cmd：新電腦的 PowerShell 預設不讓 npm 這種小程式執行，加 .cmd 就繞開，不用改電腦設定）

npm.cmd install -g @googleworkspace/cli

看 gws 裝好了沒

gws.cmd --version

gws 登入：先放好 client_secret.json，雙擊 設定信箱.cmd 最簡單。手動的話把檔放到 %USERPROFILE%\.config\gws\，再跑下面這行（引號不能省，少了引號登入看起來成功、權限卻只剩一點）

gws.cmd auth login -s "gmail,drive,calendar,sheets,docs"

看 gws 登入了沒（要看到 "has_refresh_token": true）

gws.cmd auth status
Mac

打開「終端機」（按 Command＋空白鍵，打 Terminal）。

Git：打下面這行；沒裝過會跳視窗問要不要安裝命令列開發者工具，按「安裝」。

git --version

GitHub CLI：到 cli.github.com 下載 macOS 的安裝檔（.pkg）雙擊安裝。電腦有 Homebrew（Mac 上裝工具的管理程式）的話也可以：

brew install gh

登入 GitHub

gh auth login

Node.js（要用 gws 才裝）：到 nodejs.org 下載 LTS 版（長期支援的穩定版）安裝檔。

gws

npm install -g @googleworkspace/cli

gws 登入：先把 client_secret.json 放到 ~/.config/gws/，再跑：

gws auth login -s "gmail,drive,calendar,sheets,docs"
