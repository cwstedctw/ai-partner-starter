# material：主人的參考資料（AI 只讀，不寫）

成品一律放 `workspace/outbox/`；這裡只放給 AI 讀的東西：計畫書、徵件公告、期刊投稿須知、去識別後的案例腳本、會議講義。

## 真的東西能不能放進來？先過這四條

**Private 不等於可以放研究資料。** 四條都符合才放：

1. **去識別**：受試者、學員、個案、家屬的姓名、證號、病歷號、手機整段拿掉。拼起來認得出人的（住哪、職稱加單位、少見的病史）也算。
2. **研究倫理審查（IRB）與單位同意用這家 AI**：你貼給 Codex 或 Claude，就是把資料送到 OpenAI 或 Anthropic 的雲端。計畫的同意書、IRB 核准內容、單位規範允許才放；不確定先問，問之前先去識別。
3. **允許放在這種地方**：接 GitHub 就是境外雲端。資料管理規定允許才放。
4. **接 GitHub 的話一定 Private。**

有一條不確定，就先不要放。**原件留在原本的地方**，這裡只放去識別後的版本。

## 一定不放的

- 原始問卷、SPSS 或 Excel 原始資料、錄音錄影、病歷。
- 還沒去識別的訪談逐字稿。
- 帳號、密碼、金鑰。

## 放進來之前

- Word、PDF 可以放；想讓 AI 讀得最穩，另存一份 `.txt` 或 `.md`。
- **Excel、CSV、SPSS、錄音錄影檔不會被存上 GitHub**（刻意擋掉，避免研究資料外流）。要給 AI 讀的表格，請它幫你轉成 `.md` 的表格文字再放。
- 改名的例子在 `範例-改名前後.md`。
