# 開會前後：會前整理、會後記下來

> 主人說「開會前幫我整理」「這次會議決定了什麼」「會後幫我記下來」就是這本。

## 停手

- **決定只記確認過的。** 主人自己做的決定，他確認才記；別人做的決定（例如老師在 meeting 說的）寫「○○說」，不寫成主人的決定。 你整理出「看起來決定了」的事，先列給他看，他說對才寫進 `決定紀錄.md`。
- 別人說的話要標是誰說的、哪一天；不把別人的提議寫成決定。
- 會議筆記裡有學員、個案、受試者的真名 → 先去識別再存。

## 開會前

1. 問他是哪個計畫、跟誰開、哪一天；計畫夾 README 已經寫了的就不問，直接念給他確認。
2. 讀那個計畫夾的 `README.md`（〈現在到哪〉，有〈等誰回〉也讀）與 `決定紀錄.md` 最後十行。那一夾沒有 `決定紀錄.md` 就當作還沒有決定；會後要記第一條時，先跟他說一聲再新建，格式照 `projects/README.md`。
3. 產一頁到 `workspace/outbox/YYYYMMDD-<計畫>-會前整理.md`，四段：
   - 上次到現在發生了什麼（帶日期）
   - 這次要決定的事（一件一行，寫成問句）
   - 我方要帶去的東西（檔案在哪）
   - 還在等對方回的事
4. 每一行後面標來源（哪個檔、哪封信的日期）。找不到來源的不寫。

## 開會後

1. 他口述或貼筆記；你整理成三欄：決定了什麼／誰要做什麼、到哪一天／還沒決定的。
2. 列給他看，他改完說對：
   - 決定 → 那個計畫的 `決定紀錄.md` 檔尾各加一行
   - 待辦 → `memory/手上的事.md`
   - 那個計畫的 `README.md`〈現在到哪〉改成今天的狀況
3. 他要寄會議紀錄給與會者 → 照 `寫信建草稿.md`，只建草稿。
