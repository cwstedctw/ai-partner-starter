# 寫信、回信 → 建 Gmail 草稿 → 主人按傳送

> 主人說「幫我寫信給○○」「回這封」「把這份寄給○○」就是這本。細節與指令在 `skills/gws-mail/SKILL.md`；這裡只寫順序與停手。

## 停手

- **不替主人按傳送。** 草稿建好就停，告訴他主旨與收件人。
- 收件人是一份名單（同學、學員、受試者）、內容有個資 → 名單與內容留在原本的地方，這裡只建草稿、建完刪 `cache/` 裡的 .eml。
- gws 沒登入或少授權（`403 insufficient scopes`）→ 停，照 `裝工具.md`〈gws〉的登入那一步帶主人重新登入，服務一次列全（人看的說明在 `先看這裡.html` 第 12 項）。

## 步驟

1. 問清楚三件：寄給誰（信箱）、要講什麼（主人口述或給原信）、附件在哪（檔案路徑）。
2. 寫內文：語氣與署名照 `memory/我的規矩.md`；那裡沒寫，就問一次「署名要怎麼寫」，他答了記進 `我的規矩.md`。寫好先貼在對話裡給主人看一眼。
3. 組信、建草稿：照 `skills/gws-mail/SKILL.md`〈單封〉或〈回信串原信〉。
4. 回讀：`drafts get`（metadata）核對收件人、主旨、附件數。
5. 回報：「草稿在 Gmail 草稿匣，主旨○○、收件人○○、附件 N 件，請你看過按傳送。」然後刪掉**這次自己在 `cache/_mail/` 建的** .eml 與 body.txt（公約允許的唯一刪檔例外），在 `memory/log.md` 加一行（不寫收件人全名，寫「回○○老師一封」即可）。
